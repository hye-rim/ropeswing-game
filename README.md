# 로프 스윙 🪢

고리에 줄을 걸고 그네처럼 흔들려 멀리 날아가는 원버튼 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: **화면을 꾹 누르고 있으면** 줄이 걸리고, **손을 떼면** 속도 그대로 날아갑니다. PC 는 마우스 누르기 또는 `Space`/`↑`/`W`/`Enter` 누르고 있기, `P` 일시정지, `M` 소리. 창이 가려지면 저절로 일시정지합니다.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 누르면 **앞쪽 위로 닿는 거리(240) 안**의 고리 중 가장 알맞은 하나에 줄이 걸립니다(깜빡이는 고리가 걸릴 고리). 닿는 고리가 없으면 걸리지 않습니다.
- 매달려 있는 동안 줄이 조금씩 짧아지고(초당 36, 최소 80), 줄이 짧아질수록 빨라집니다(각운동량 보존). 줄은 늘어나지 않고 팽팽할 때만 당깁니다. 손을 떼면 속도를 그대로 가진 채 중력(1000)으로 날아갑니다.
- 고리는 오른쪽으로 끝없이 이어지고, 멀어질수록 간격이 조금씩 벌어집니다(최대 +150). 고리 사이에는 **코인**(+5점)이 호 모양으로 놓입니다.
- 끝나는 경우: **용암**에 닿음 · 길 중간의 **바위**에 부딪힘(보통 25m부터, 쉬움 70m부터) · 뒤에서 쫓아오는 **불길**에 잡힘(초당 55로 시작해 멀어질수록 빨라져 최대 190). 멈춰 있으면 불길에 잡힙니다.
- 점수 = 달린 거리(m, 10 길이 = 1m) + 코인 × 5. **보통에서만 최고 점수가 저장됩니다.**

| | 쉬움 | 보통 |
|---|---|---|
| 목숨 | **3개** (용암·바위에 빠지면 가까운 고리 아래에서 다시 시작, 불길은 목숨과 상관없이 끝) | 1개 |
| 줄이 닿는 거리 | 290 | 240 |
| 고리 간격 | 95~150 (멀어져도 최대 +50) | 150~235 (최대 +150) |
| 용암 높이 | 760 (더 아래) | 620 |
| 쫓아오는 불길 | 처음 25 → 최대 90 | 처음 55 → 최대 190 |
| 바위 | 150m 부터, 12% | 25m 부터, 40% |

## 균형을 어떻게 맞췄나
- (이전 측정) 같은 규칙으로 두 가지 봇을 20판씩 돌렸습니다. ① 「누르고 1.1초 뒤에 놓기」만 반복하는 봇 ② 놓은 뒤의 포물선이 다음 고리에 닿을 때만 놓는 봇. 결과: 쉬움 ① 중앙값 200m ② 673m, 보통 ① 391m ② 455m(최고 1664m).
- 처음에는 ① 봇이 한 고리에 매달려 영원히 살아남아서 **쫓아오는 불길**을 넣었습니다. 시작 고리가 닿는 거리 밖이라 첫 누르기가 허공이던 것도 고쳤습니다.
- **쉬움 완화(2026-11-04)**: 「쉬움도 너무 어렵다」는 의견으로 조정. 반응이 느리고 타이밍이 흔들리는 봇(누르는 데 0.25초 지연, 놓는 시점 ±0.18초 오차)으로 40판씩 비교했습니다. 쉬움 중앙값 21m → 96m(정확한 봇은 56m → 157m), 보통은 그대로 20m 안팎(정확한 봇 73m).
- **사람의 실제 체감 난이도와 폰 터치 감각은 측정하지 못했습니다.**

## 참고한 것과 제가 정한 값
- 「줄을 걸고 흔들려 날아가는 원버튼 게임」이라는 널리 알려진 형식을 따랐고, 중력·줄 길이·간격·불길 속도·점수는 모두 제가 정한 값입니다. 온라인 대전은 없습니다.
